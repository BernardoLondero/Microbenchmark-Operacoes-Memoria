# Microbenchmark-de-Operacoes-em-Memoria

Repositório destinado aos artefatos do experimento de microbenchmark comparativo entre os sistemas operacionais Windows e Linux.

## Objetivo do Projeto
O objetivo desta investigação é determinar, em condições experimentais equivalentes, qual dos dois sistemas operacionais (Windows ou Linux) apresenta o melhor desempenho no processamento de dados em memória.
